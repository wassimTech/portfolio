#### **Projet 5 : Obydo : Application Web pour la gestion des invendus**

##### **Développeur front-end**

**Description :** Obydo est une application web conçue pour aider les entreprises à gérer leurs invendus, qu'ils soient neufs ou d'occasion, en leur offrant des solutions pour les vendre, les donner ou les recycler. Le système permet aux entreprises de créer des enchères pour leurs produits invendus et de remplir les informations correspondantes. Les clients peuvent alors consulter ces enchères, remplir leurs informations et participer en offrant des enchères sur les produits. Lorsque le temps d'une enchère est écoulé, si le produit n'a pas été vendu, il est transformé en don ou recyclé. Les associations ont également la possibilité de récupérer ces invendus non vendus, dans le respect des lois françaises concernant la gestion des invendus.

Le paiement est effectué via la solution Mongopay pour garantir la sécurité des transactions.

#### **Taches :**

- Intégrer les API nécessaires pour la gestion des paiements via Mongopay, l'envoi des informations sur les produits et les enchères, ainsi que la création des factures.
